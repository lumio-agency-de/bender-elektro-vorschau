# Bender Elektro — Website-Vorschau (V2)

Relaunch-Entwurf für **Jürgen Bender Elektroinstallationsbetrieb**, An der Röte 5 a, 74889 Sinsheim —
auf Basis der Original-Website bender-elektro.de (Texte & Farbwelt übernommen).

- **Design:** hell, Signal-Rot #E20018 / Fast-Schwarz / Weiß (aus dem Logo-Blitz), Barlow Condensed Italic + Barlow (selbst gehostet)
- **Signature:** der rote Logo-Blitz als durchgehendes Leitmotiv (Hero-Zeichnung, Glyphen, Schräg-Schnitte)
- **Struktur:** Mehrseiter wie das Original — Start, Leistungen (5 Unterseiten), Wir über uns, Kontakt, Impressum, Datenschutz
- **Bilder:** automatische Bild-Slots (`img/<slot>.jpg`) — Datei ablegen genügt, kein Code nötig. Slots: hero, elektroinstallation, modernisieren, service, hausgeraete, telefonanlagen, betrieb
- Vorschau ist `noindex` + robots.txt-Disallow. `.htaccess` (Sicherheits-Header) greift beim Umzug auf einen Apache-Hoster.

V1 (One-Pager, Electric-Blue) liegt in der Git-Historie.
